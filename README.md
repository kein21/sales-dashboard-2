#  Super Store Sales Dashboard

 Project Overview
This project is an interactive Excel-based Sales Dashboard developed to analyze Super Store sales performance. The dashboard provides insights into sales trends, profit analysis, product performance, category distribution, and customer purchasing patterns.

Objectives
- Analyze overall sales performance.
- Monitor monthly profit trends.
- Identify top-performing products.
- Compare sales across weekdays.
- Evaluate category and sub-category performance.
- Support data-driven business decisions.

 Tools & Techniques Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Cleaning
- Data Visualization
- Dashboard Design

 Key Performance Indicators (KPIs)
- Total Sales: ₹23,26,534.35
- Total Sub-Category Count: 10,194

 Dashboard Insights

 1. Monthly Profit Analysis
- Displays profit trends across all months.
- Helps identify peak and low-profit periods.

 2. Top 10 Product Profit
- Highlights the most profitable products.
- Assists in product performance evaluation.

 3. Day-wise Sales Analysis
- Compares sales performance across weekdays.
- Identifies high-sales days.

4. Product Profit Analysis
- Shows sales and profit comparison by product category.
- Helps understand category contribution.

5. Sub-Category vs Discount vs Sales
- Analyzes the relationship between discounts and sales.
- Supports pricing and discount strategy decisions.

 6. Category Distribution
- Visualizes sales contribution by category.
- Provides an overview of product mix performance.
